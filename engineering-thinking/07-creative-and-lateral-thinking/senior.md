# Creative and Lateral Thinking — Senior

Senior creativity balances exploration with production responsibility.

Maintain an option portfolio: safe incremental improvements, bounded experiments, and a small number of high-upside bets. Define the uncertainty each experiment retires, maximum blast radius, budget, success evidence, and stop condition.

Constraints can create focus. A hard latency budget, offline requirement, or “no new service” rule can reveal simpler designs. But distinguish productive constraints from inherited assumptions.

## Test yourself

1. How would you balance incremental and transformational options?
2. What makes an experiment safe but informative?
3. Which constraint focuses design, and which merely preserves history?
4. When should an option be killed?
