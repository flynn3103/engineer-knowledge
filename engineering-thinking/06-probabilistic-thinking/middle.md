# Probabilistic Thinking — Middle

Start with a base rate: how often do similar migrations, incidents, or projects succeed? Then update with specific evidence. A vivid recent event should not replace the reference class.

Expected value multiplies outcomes by probabilities, but also consider downside limits, reversibility, learning value, and utility. A small experiment may have high value because it cheaply changes the decision.

Use confidence intervals and sensitivity analysis instead of false precision. Identify which input can flip the choice and gather evidence there.

## Test yourself

1. What is a useful reference class for a database migration?
2. When does expected monetary value hide unacceptable risk?
3. Which variable deserves sensitivity analysis?
4. What is the value of information from a pilot?
