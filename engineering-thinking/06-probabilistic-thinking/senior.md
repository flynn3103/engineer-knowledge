# Probabilistic Thinking — Senior

System failures are rarely independent. Shared cloud regions, credentials, deployment pipelines, and libraries create correlated risk. Multiplying independent probabilities can produce dangerously optimistic reliability estimates.

Model fault trees, common causes, conditional probabilities, and tail outcomes. Use error budgets, redundancy, isolation, hedging, and recovery drills according to impact and risk appetite.

Communicate uncertainty without paralysis: state the distribution, assumptions, worst credible outcome, mitigation, and trigger to change course.

## Test yourself

1. Which shared dependency correlates supposedly redundant services?
2. Why can average latency hide user risk?
3. How does an error budget turn probability into action?
4. What evidence changes your worst credible scenario?
