# Chaos Engineering — Senior

Run game days with roles, hypotheses, scope, safety controls, communication, and restoration. Include compound and recovery failures only after single-fault confidence.

Convert findings into tests, capacity, runbooks, architecture, and ownership changes. A game day that only demonstrates failure creates theater, not resilience.

## Test yourself

1. Which compound fault is credible?
2. Who holds abort authority?
3. How do you test restoration order?
4. Which finding becomes an automated guardrail?
