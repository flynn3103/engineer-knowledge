# Snapshot & Approval Testing

Use snapshots and approvals for outputs that are valuable to review as a whole and stable enough to trust.

## Learn by level

- [Junior](junior.md) — create and review a meaningful snapshot.
- [Middle](middle.md) — control inputs and prevent noisy updates.
- [Senior](senior.md) — choose where approvals provide real safety.
- [Professional](professional.md) — maintain review standards that prevent snapshot drift.

## Apply it

1. Use a deterministic input.
2. Snapshot only a meaningful, reviewable output.
3. Inspect every change rather than accepting it automatically.
4. Prefer explicit assertions when the expected value is simple.
