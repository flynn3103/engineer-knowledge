# Integration Testing

Use integration tests to prove that real components work together at an important boundary.

## Learn by level

- [Junior](junior.md) — recognize the boundary an integration test proves.
- [Middle](middle.md) — use realistic dependencies with controlled setup.
- [Senior](senior.md) — manage isolation, reliability, and system risk.
- [Professional](professional.md) — scale an integration-test practice across teams.

## Apply it

1. Choose one database, message, or HTTP boundary.
2. Set up the smallest realistic environment.
3. Verify the contract and failure behavior.
4. Reset state so the result is repeatable.
