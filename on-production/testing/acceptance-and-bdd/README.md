# Acceptance & BDD

Use acceptance examples and behavior-driven development to align product, delivery, and verification around observable behavior.

## Learn by level

- [Junior](junior.md) — write clear, testable acceptance examples.
- [Middle](middle.md) — collaborate on examples before implementation.
- [Senior](senior.md) — keep executable specifications focused and reliable.
- [Professional](professional.md) — make shared behavior discovery a durable team practice.

## Apply it

1. Describe the user outcome in concrete examples.
2. Discuss examples with product, delivery, and test stakeholders.
3. Automate only the scenarios that provide lasting value.
4. Keep wording business-focused and implementation-independent.
