# Mutation Testing

Use mutation testing to discover whether a test suite notices small but meaningful code changes.

## Learn by level

- [Junior](junior.md) — understand killed and surviving mutants.
- [Middle](middle.md) — improve weak assertions from mutation results.
- [Senior](senior.md) — use mutation testing efficiently on high-risk code.
- [Professional](professional.md) — set practical mutation-testing policy and metrics.

## Apply it

1. Start with a small, high-value module.
2. Run mutation testing against its focused suite.
3. Investigate surviving mutants rather than chasing a score blindly.
4. Add the smallest assertion or case that detects a real gap.
