# Property-Based Testing

Use property-based testing to verify invariants across more inputs than hand-written examples can cover.

## Learn by level

- [Junior](junior.md) — distinguish examples from properties.
- [Middle](middle.md) — write generators, properties, and shrinking-friendly checks.
- [Senior](senior.md) — use properties for complex domains and regressions.
- [Professional](professional.md) — introduce property testing where it gives the most confidence.

## Apply it

1. State an invariant that must always hold.
2. Generate inputs that include boundaries and unusual cases.
3. Keep failed examples as regression tests.
4. Check that the property is strong enough to reject real faults.
