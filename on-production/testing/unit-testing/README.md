# Unit Testing

Use unit tests to verify focused behavior quickly, without relying on real I/O, clocks, or networks.

## Learn by level

- [Junior](junior.md) — write small, deterministic checks.
- [Middle](middle.md) — choose isolation and useful assertions.
- [Senior](senior.md) — design seams and maintain trusted feedback.
- [Professional](professional.md) — set standards that keep unit tests valuable.

## Apply it

1. Pick one rule or edge case.
2. Control inputs and dependencies.
3. Assert the observable result clearly.
4. Keep the test fast enough to run continuously.
