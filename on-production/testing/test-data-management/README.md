# Test Data Management

Use safe, deterministic data so tests are readable, repeatable, and representative of real risk.

## Learn by level

- [Junior](junior.md) — create focused fixtures and builders.
- [Middle](middle.md) — manage determinism, seeds, and realistic variations.
- [Senior](senior.md) — handle data volume, ownership, and cross-service setup.
- [Professional](professional.md) — establish safe data practices across environments.

## Apply it

1. Create only the data the test needs.
2. Keep asserted values explicit and deterministic.
3. Avoid production personal data unless it is properly protected.
4. Reset or isolate data after each test.
