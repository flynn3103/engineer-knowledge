# Contract Testing

Use contract tests to keep consumers and providers compatible without relying on broad end-to-end coverage.

## Learn by level

- [Junior](junior.md) — understand what a contract proves.
- [Middle](middle.md) — write and verify consumer expectations.
- [Senior](senior.md) — manage versioning and boundary risk.
- [Professional](professional.md) — operate contracts across many teams.

## Apply it

1. Identify a consumer-provider boundary.
2. Record the request and response behavior the consumer needs.
3. Verify the provider against that behavior in CI.
4. Version and retire contracts deliberately.
