# Performance & Load Testing

Use performance and load tests to validate latency, throughput, and capacity under realistic demand.

## Learn by level

- [Junior](junior.md) — measure a baseline and read the result.
- [Middle](middle.md) — model workloads and identify bottlenecks.
- [Senior](senior.md) — design experiments that protect service objectives.
- [Professional](professional.md) — make performance testing a continuous organizational practice.

## Apply it

1. Define a workload and success threshold.
2. Use representative data and traffic shape.
3. Measure percentiles, errors, and saturation together.
4. Compare results to a baseline before and after a change.
