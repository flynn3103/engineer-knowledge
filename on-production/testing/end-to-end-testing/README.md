# End-to-End Testing

Use end-to-end tests sparingly to protect the critical journeys a user must be able to complete.

## Learn by level

- [Junior](junior.md) — identify a valuable end-to-end journey.
- [Middle](middle.md) — make browser and API flows reliable.
- [Senior](senior.md) — protect high-risk workflows without creating a slow suite.
- [Professional](professional.md) — govern end-to-end coverage and its cost.

## Apply it

1. Choose one business-critical journey.
2. Set up only the state that journey needs.
3. Assert a user-visible outcome.
4. Replace timing guesses with explicit readiness checks.
