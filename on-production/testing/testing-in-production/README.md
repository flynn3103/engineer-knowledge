# Testing in Production

Use controlled production techniques to learn about behavior that pre-production environments cannot fully reproduce.

## Learn by level

- [Junior](junior.md) — understand safe production checks.
- [Middle](middle.md) — use canaries, synthetic checks, and feature flags responsibly.
- [Senior](senior.md) — manage blast radius, observability, and rollback.
- [Professional](professional.md) — build platform guardrails for safe learning in production.

## Apply it

1. State the hypothesis and the safety boundary.
2. Limit exposure with a flag, canary, or shadow traffic.
3. Monitor the user and system signals that would stop the experiment.
4. Keep rollback immediate and rehearsed.
