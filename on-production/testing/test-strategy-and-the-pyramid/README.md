# Test Strategy & the Pyramid

Use a test strategy to put each check at the cheapest level that can prove the behavior.

## Learn by level

- [Junior](junior.md) — identify unit, integration, and end-to-end tests.
- [Middle](middle.md) — choose boundaries and balance the test portfolio.
- [Senior](senior.md) — protect confidence, feedback speed, and system invariants.
- [Professional](professional.md) — manage strategy as a measurable team practice.

## Apply it

1. List the failures a change could introduce.
2. Put each check at the lowest useful test level.
3. Keep the fast feedback layer broad and the slow layer deliberate.
4. Review the questions at the end of your level guide.
