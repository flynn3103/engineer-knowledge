# Feature Flags & Progressive Delivery

Control when a deployed capability is exposed, and expand exposure only with evidence.

## Learn by level

- [Junior](junior.md) — use a flag safely and understand its lifecycle.
- [Middle](middle.md) — plan a canary, ring, or percentage rollout.
- [Senior](senior.md) — protect compatibility while both paths are live.
- [Professional](professional.md) — establish flag governance and measurable rollout practice.

## Apply it

1. Define the audience, success signal, and stop condition.
2. Start with a small, observable cohort.
3. Keep a tested kill switch and a safe off-path.
4. Remove the flag and dead code after the rollout finishes.

Use the review questions at the end of each guide to confirm understanding.
