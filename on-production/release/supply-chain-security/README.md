# Supply-Chain Security

Protect the release path from source code through build, publication, and consumption.

## Learn by level

- [Junior](junior.md) — identify dependencies, lockfiles, SBOMs, and trusted sources.
- [Middle](middle.md) — verify artifacts and respond to dependency risk.
- [Senior](senior.md) — enforce trust boundaries and fail-closed controls.
- [Professional](professional.md) — govern suppliers, platform controls, and incident response.

## Apply it

1. Pin dependencies and keep an inventory of what ships.
2. Generate an SBOM and provenance during each build.
3. Verify signatures and expected builder identity before use.
4. Rehearse the response to a disclosed dependency vulnerability.

Use the review questions at the end of each guide to confirm understanding.
