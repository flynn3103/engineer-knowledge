# Release Branching & Trains

Choose a release flow that keeps delivery predictable without making integration unsafe.

## Learn by level

- [Junior](junior.md) — follow the branch, tag, and promotion steps.
- [Middle](middle.md) — compare trunk-based delivery, release branches, and trains.
- [Senior](senior.md) — manage candidates, hotfixes, and cross-team dependencies.
- [Professional](professional.md) — define organization-wide cadence and ownership.

## Apply it

1. Define the source of truth for a release candidate.
2. Keep branch lifetime and merge-back rules explicit.
3. Set promotion criteria before the release window opens.
4. Rehearse the hotfix path from a production tag.

Use the review questions at the end of each guide to confirm understanding.
