# Rollback & Roll-Forward

Recover from a bad release using the safest and fastest path for the failure.

## Learn by level

- [Junior](junior.md) — roll back to a known-good artifact using the runbook.
- [Middle](middle.md) — choose rollback, revert, or roll-forward for a local incident.
- [Senior](senior.md) — design migration and retention rules that keep recovery possible.
- [Professional](professional.md) — set recovery policy, ownership, and learning loops.

## Apply it

1. Retain and identify known-good artifacts.
2. Define the decision rule for rollback versus roll-forward.
3. Exercise the recovery path before an incident.
4. Record the decision, impact, and prevention follow-up.

Use the review questions at the end of each guide to confirm understanding.
