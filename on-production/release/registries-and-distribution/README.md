# Registries & Distribution

Publish release artifacts through a dependable, immutable distribution path.

## Learn by level

- [Junior](junior.md) — publish and retrieve a versioned artifact safely.
- [Middle](middle.md) — configure retention, access, and package lifecycle rules.
- [Senior](senior.md) — design distribution for scale, recovery, and trust.
- [Professional](professional.md) — govern registry policy and ownership across the organization.

## Apply it

1. Publish immutable versions or digests.
2. Set retention so known-good artifacts remain recoverable.
3. Restrict publishing and record who promoted an artifact.
4. Test retrieval from the same path used in production.

Use the review questions at the end of each guide to confirm understanding.
