# Release Automation

Automate repeatable release work while keeping policy checks visible and auditable.

## Learn by level

- [Junior](junior.md) — run and verify an automated release workflow.
- [Middle](middle.md) — connect versioning, notes, publishing, and promotion.
- [Senior](senior.md) — design reliable gates, recovery, and manual exception paths.
- [Professional](professional.md) — provide a secure platform and adoption standards.

## Apply it

1. Automate deterministic steps from tag to publish.
2. Fail closed on tests, policy, and provenance checks.
3. Keep a documented, audited path for exceptions.
4. Measure lead time, failure rate, and recovery time.

Use the review questions at the end of each guide to confirm understanding.
