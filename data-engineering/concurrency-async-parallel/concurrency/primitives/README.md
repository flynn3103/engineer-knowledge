# Primitives

> Covers Atomic, Channels, Condition Variables, Mutex, and Semaphore.

## Topics

| Topic | What it covers |
|---|---|
| [Atomic](atomic/) | An atomic operation appears indivisible and can establish visibility between threads. |
| [Channels](channels/) | A channel transfers values between concurrent tasks while coordinating senders and receivers. |
| [Condition Variables](condition-variables/) | A condition variable lets threads sleep until shared state may satisfy a predicate. |
| [Mutex](mutex/) | A mutex lets one thread at a time enter a critical section that protects an invariant. |
| [Semaphore](semaphore/) | A semaphore uses permits to bound how many operations may use a resource concurrently. |
