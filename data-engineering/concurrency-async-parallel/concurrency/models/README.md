# Models

> Covers Actor Model, CSP, Message Passing, Shared Memory, and STM.

## Topics

| Topic | What it covers |
|---|---|
| [Actor Model](actor-model/) | An actor owns state, processes one message at a time, and communicates only by messages. |
| [CSP](csp/) | CSP builds concurrent systems from sequential processes that synchronize through channels. |
| [Message Passing](message-passing/) | Components exchange explicit messages instead of changing the same state. |
| [Shared Memory](shared-memory/) | Threads communicate by reading and changing the same memory; synchronization makes those changes safe and visible. |
| [STM](stm/) | STM groups memory changes into transactions that commit together or retry after conflict. |
