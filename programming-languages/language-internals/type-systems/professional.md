# Type Systems — Professional

Rust uses affine ownership and lifetimes; Haskell combines algebraic data types, type classes, and effects represented through types; TypeScript applies structural typing over JavaScript; JVM generics use erasure; .NET reifies more generic information. These mechanisms trade expressiveness, runtime representation, compilation cost, and ecosystem compatibility.

Govern public type evolution, checker performance, escape hatches, and diagnostic quality. Further reading: Pierce’s *Types and Programming Languages*, language specifications, and papers on ownership, gradual typing, and effect systems.
