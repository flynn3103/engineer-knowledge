# Choosing a Language — Senior

Adoption creates build, security, observability, hiring, review, deployment, and upgrade obligations. Prefer a service or serialization boundary for incremental adoption. Define ownership, supported versions, dependency policy, incident support, success metrics, and an exit path before rollout.

Model total cost: implementation speed, infrastructure, failure recovery, ecosystem gaps, migration, and years of maintenance.

## Test yourself

1. What is the smallest reversible adoption boundary?
2. Which team owns runtime upgrades?
3. What metric triggers expansion or rollback?
