# Metaprogramming — Senior

Treat generators and macro systems as compilers: precise diagnostics, source locations, reproducibility, compatibility, security review, and tests for output. Bound reflection to framework edges. Provide an escape hatch when generated behavior cannot express a real requirement.

## Test yourself

1. How do generated APIs evolve compatibly?
2. What enters the build cache key?
3. How do you debug expanded code?
