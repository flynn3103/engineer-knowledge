# Metaprogramming — Middle

Compile-time generation gives inspectable artifacts and earlier failures. Runtime reflection adapts dynamically but shifts failures later and adds lookup cost. Hygienic macros avoid accidental name capture; schema-driven generators require deterministic output and versioned inputs.
