# Runtime Systems — Professional

HotSpot uses tiered compilation, inline caches, safepoints, and several collectors. V8 combines hidden classes, Ignition bytecode, TurboFan, and deoptimization. CPython’s evaluation loop works with refcounted objects and extension APIs. Go coordinates goroutine scheduling, stack growth, escape analysis, and concurrent GC.

Dashboard compilation queues, deoptimizations, code cache, pauses, allocation, scheduler latency, and module growth. Further reading: OpenJDK, V8, CPython, and Go runtime source trees.
