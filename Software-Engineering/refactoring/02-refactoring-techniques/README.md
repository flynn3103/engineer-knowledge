# Refactoring Techniques

> Small, behaviour-preserving transformations — rename a method, extract a fragment, push a field up the inheritance chain — that together form the practical vocabulary for paying down design debt.

## How to use this section

Each topic has five depth levels — **junior → middle → senior → professional** — plus an **interview** Q&A bank and hands-on **tasks**. Each topic folder also includes `find-bug.md` (snippets where a technique was applied wrong) and `optimize.md` (refactorings that look correct but have subtle performance issues). Start at your level and climb.
