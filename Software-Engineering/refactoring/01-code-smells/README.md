# Code Smells

> Warnings, not bugs — patterns in code with a high probability of indicating something wrong with the design. A smell is the question; a refactoring technique is the answer.

## Topics

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 01 | [Bloaters](01-bloaters/junior.md) | Long Method, Large Class, Primitive Obsession, Long Parameter List, Data Clumps — code that has grown too large |
| 02 | [Object-Orientation Abusers](02-oo-abusers/junior.md) | Switch Statements, Temporary Field, Refused Bequest, Alternative Classes with Different Interfaces |
| 03 | [Change Preventers](03-change-preventers/junior.md) | Divergent Change, Shotgun Surgery, Parallel Inheritance Hierarchies — one change that forces many |
| 04 | [Dispensables](04-dispensables/junior.md) | Comments, Duplicate Code, Lazy Class, Data Class, Dead Code, Speculative Generality |
| 05 | [Couplers](05-couplers/junior.md) | Feature Envy, Inappropriate Intimacy, Message Chains, Middle Man — classes that know too much about each other |

## How to use this section

Each topic has five depth levels — **junior → middle → senior → professional** — plus an **interview** Q&A bank and hands-on **tasks**. Each topic folder also includes `find-bug.md` (buggy snippets to fix) and `optimize.md` (inefficient implementations to refactor). Start at your level and climb.
