# Structural Patterns

> How objects and classes assemble into larger structures while staying flexible, efficient, and decoupled — the answer to "how do these objects relate to each other?"

## Topics

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 01 | [Adapter](01-adapter/junior.md) | Making objects with incompatible interfaces collaborate |
| 02 | [Bridge](02-bridge/junior.md) | Splitting closely related classes into separate abstraction/implementation hierarchies |
| 03 | [Composite](03-composite/junior.md) | Composing objects into tree structures and treating them uniformly |
| 04 | [Decorator](04-decorator/junior.md) | Attaching new behaviors to objects via wrapper objects |
| 05 | [Facade](05-facade/junior.md) | Providing a simplified interface to a complex subsystem |
| 06 | [Flyweight](06-flyweight/junior.md) | Fitting more objects into memory by sharing common state |
| 07 | [Proxy](07-proxy/junior.md) | Providing a substitute that controls access to another object |

## How to use this section

Each topic has five depth levels — **junior → middle → senior → professional** — plus an **interview** Q&A bank and hands-on **tasks**. Each topic folder also includes `find-bug.md` and `optimize.md` practice files. Start at your level and climb.
