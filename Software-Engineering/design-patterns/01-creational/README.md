# Creational Patterns

> Object creation mechanisms that increase flexibility and reuse — hiding *what*, *who*, and *how* objects are instantiated, decoupling consumers from concrete classes.

## Topics

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 01 | [Factory Method](01-factory-method/junior.md) | Providing an interface for creating objects in a superclass while letting subclasses alter the type created |
| 02 | [Abstract Factory](02-abstract-factory/junior.md) | Producing families of related objects without specifying their concrete classes |
| 03 | [Builder](03-builder/junior.md) | Constructing complex objects step by step |
| 04 | [Prototype](04-prototype/junior.md) | Copying existing objects without making code dependent on their classes |
| 05 | [Singleton](05-singleton/junior.md) | Ensuring a class has only one instance with a global access point |

## How to use this section

Each topic has five depth levels — **junior → middle → senior → professional** — plus an **interview** Q&A bank and hands-on **tasks**. Each topic folder also includes `find-bug.md` and `optimize.md` practice files. Start at your level and climb.
