# Design Anti-Patterns

> Class- and module-level mistakes — the wrong shapes for OO structures, the wrong allocation of responsibilities, the wrong abstraction.

## Topics

| # | Topic | What you'll learn |

| 01 | [OO Misuse](01-oo-misuse/junior.md) | Anemic Domain Model, BaseBean, Constant Interface, Poltergeist, Object Orgy, Functional Decomposition, Call Super, Magic Container, Flag Arguments, Telescoping Constructor, Fragile Base Class |

## How to use this section

Each topic has five depth levels — **junior → middle → senior → professional** — plus an **interview** Q&A bank and hands-on **tasks**. Each topic folder also includes `find-bug.md` (spot-the-anti-pattern drills) and `optimize.md` (flawed designs to redesign). Start at your level and climb.
