# Development Anti-Patterns

> Code-level habits individual developers introduce, often unintentionally, in day-to-day work — the kind you can usually spot by reading a single file.

## Topics

| # | Topic | What you'll learn |
|---|-------|-------------------|
| 01 | [Bad Structure](01-bad-structure/junior.md) | God Object, Spaghetti Code, Lava Flow, Boat Anchor, Arrow Anti-Pattern — code shaped to resist change |

| 03 | [Over-Engineering](03-over-engineering/junior.md) | Premature Optimization, Speculative Generality, Gold Plating, Yo-yo Problem, Lasagna Code, Accidental Complexity, Soft Coding, Bikeshedding — effort spent solving problems you don't have |

## How to use this section

Each topic has five depth levels — **junior → middle → senior → professional** — plus an **interview** Q&A bank and hands-on **tasks**. Each topic folder also includes `find-bug.md` (spot-the-anti-pattern drills) and `optimize.md` (flawed implementations to refactor). Start at your level and climb.
