# Scientific Thinking — Middle

Design experiments around a causal contrast. Define treatment, control or baseline, population, metric, duration, sample, and analysis before observing results.

For performance work, control warmup, environment, input distribution, concurrency, and measurement overhead. For product A/B tests, define randomization unit, primary outcome, guardrails, and novelty or seasonality risks.

Use a spike to retire architectural uncertainty: can the dependency meet throughput, security, and operability constraints? Do not let exploratory code silently become production code.

## Test yourself

1. What is the causal contrast in your experiment?
2. Which variable could confound a benchmark?
3. Why define one primary metric in advance?
4. What learning ends a spike?
