# Systems Thinking — Professional

Professional systems thinking treats technology, teams, incentives, finance, and governance as one adaptive system.

Architecture boundaries shape communication; funding shapes ownership; incident policy shapes disclosure; metrics shape behavior. Interventions must account for these feedback paths.

## Operate with leading indicators

Pair outcome metrics with signals that show system state early: queue age, change failure rate, dependency saturation, ownership gaps, review wait time, toil, and recovery rehearsal. Use game days and simulations to test the mental model.

## Portfolio decisions

Manage resilience, platform investment, migration, and technical debt as interacting stocks and flows. Track creation and removal rates, not only the current backlog.

## Checklist

1. Define system purpose and competing goals.
2. Map technical and organizational boundaries.
3. Identify stocks, flows, loops, delays, and constraints.
4. Predict adaptation and second-order effects.
5. Choose a reversible intervention with leading indicators.
6. Re-map after behavior changes.

```text
PURPOSE -> STRUCTURE -> BEHAVIOR -> FEEDBACK -> ADAPTATION
             technical + organizational + economic
```

## Test yourself

1. How can platform standardization increase local delivery time?
2. Which leading indicators reveal declining resilience?
3. Model technical debt as a stock with creation and removal flows.
4. What makes an intervention reversible in a socio-technical system?
