# What Is Technical Debt — Senior

## Goal

Reason about debt as capacity, optionality, and systemic risk.

## Strategic view

- Interest grows when high-churn work repeatedly crosses a weak boundary.
- A system enters a debt spiral when interest consumes more capacity than repayment.
- Some debt is rational under uncertainty when it preserves options and is reversible.
- Irreversible decisions deserve more design, evidence, and rollback planning.

## Ask

- What future change becomes expensive?
- How likely is that change?
- What is the earliest signal that the debt must be paid?
- Which other debts compound with it?
