# Preventing Accumulation — Junior

## Goal

Prevent new debt through everyday delivery habits.

## Definition of done

- Behavior is tested.
- Code is reviewed and understandable.
- Important decisions and operational changes are documented.
- Known shortcuts are visible with an owner or follow-up.

## Habits

- Make small pull requests.
- Write tests while rules are fresh.
- Clean small issues in code you touch.
- Raise uncertainty before it becomes a hidden shortcut.

## Practice

Before opening a pull request, identify one thing that would make the next change harder and address or record it.
