# The Debt Quadrant — Senior

## Goal

Use classification as input to a system-level debt strategy.

## Strategic use

- Look for debt that migrates from deliberate-prudent to reckless when repayment is repeatedly deferred.
- Identify process failures behind each cell: discovery, incentives, governance, or capability.
- Set different controls: tolerate, track, gate, or stop.
- Audit classifications against evidence to counter hindsight bias.

## Remember

The quadrant is not a verdict on people. It is a prompt to improve the system that produces decisions.
