# Technical Debt — Senior

Manage debt across architecture, data, testing, operations, security, and organization. Use hotspot and dependency maps to find debt that constrains important change paths.

Sequence repayment with product delivery: characterization, compatibility layer, expand-contract migration, traffic shift, and old-path removal. Define risk indicators and stop adding exposure while remediation proceeds.

Prevent accumulation with architecture fitness functions, supported-version policies, dependency automation, SLOs, and ownership. Avoid universal debt percentages; allocate capacity according to evidence and strategic risk.

## Test yourself

1. Which debt blocks the highest-value change path?
2. How does operational debt differ from code debt?
3. What guardrail stops further accumulation?
4. How do you make repayment incremental?
