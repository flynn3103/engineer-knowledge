# Planning — Professional

**Your question:** How do I build planning systems? How do I measure planning quality? How do I scale planning across teams?

Professional level teaches you to build planning systems and processes that enable effective planning at scale. You're establishing planning norms, measuring planning health, and creating an environment where teams can plan effectively.

## Planning system components

A planning system includes:

1. **Planning framework:** OKRs, Epics, Stories, Tasks
2. **Planning process:** How teams plan (meetings, documentation, review)
3. **Planning tools:** Jira, Asana, or other tools
4. **Planning metrics:** How you measure planning quality
5. **Planning culture:** How teams think about planning

## Planning framework

Establish a consistent framework across teams:

| Level | What | Example |
|---|---|---|
| OKR | Business goal | "Improve user engagement with their profile" |
| Epic | Large initiative | "User Profile System" |
| Story | User-facing feature | "As a user, I can view my profile" |
| Task | Concrete work | "Build profile API" |

## Planning process

Establish a consistent process:

1. **Quarterly planning:** Define OKRs and Epics for the quarter
2. **Sprint planning:** Break Epics into Stories and Tasks for the sprint
3. **Daily standup:** Track progress and identify blockers
4. **Retrospective:** Reflect on what went well and what to improve

## Planning metrics

Track whether planning is working:

| Metric | What it tells you | Healthy signal |
|---|---|---|
| Plan accuracy | Are plans realistic? | >80% of planned work is completed |
| Scope clarity | Are Stories clear? | <10% of Stories need clarification |
| Estimation accuracy | Are estimates realistic? | Actual vs. estimated variance <20% |
| Dependency identification | Are dependencies identified? | <5% of work is blocked by dependencies |
| Stakeholder alignment | Are stakeholders aligned? | >80% of stakeholders agree on plan |
| Planning efficiency | How long does planning take? | Planning takes <10% of sprint time |

## Realistic scenario: Building a planning system

**Current state (50 engineers, 5 teams):**
- Teams plan differently
- Plans are vague
- Estimates are inaccurate
- Stakeholders are misaligned
- Planning takes too long

**Target state (100 engineers, 10 teams):**
- Teams plan consistently
- Plans are clear
- Estimates are accurate
- Stakeholders are aligned
- Planning is efficient

**Implementation plan:**

### Phase 1: Establish framework (Month 1)

**Define planning framework:**
- OKR template
- Epic template
- Story template
- Task template

**Example OKR template:**
```
Objective: [What do you want to achieve?]

Key Results:
1. [Measurable outcome 1]
2. [Measurable outcome 2]
3. [Measurable outcome 3]

Why it matters: [Why is this important?]

Risks: [What could go wrong?]
```

**Example Epic template:**
```
Epic: [Name]

OKR:
- Objective: [What do you want to achieve?]
- Key Results: [Measurable outcomes]

Stories:
1. [Story 1]
2. [Story 2]
3. [Story 3]

Effort estimate: [Total days]

Dependencies: [What must happen first?]
```

**Example Story template:**
```
Story: [Name]

As a [user type], I can [action], so that [benefit]

Acceptance criteria:
- [ ] [Criterion 1]
- [ ] [Criterion 2]
- [ ] [Criterion 3]

Effort estimate: [Days]

Dependencies: [What must happen first?]
```

### Phase 2: Teach planning skills (Month 2-3)

**Teach how to write OKRs:**
- What makes a good OKR?
- How to measure success?
- How to avoid common mistakes?

**Teach how to define Epics:**
- How to break down large initiatives?
- How to estimate effort?
- How to identify dependencies?

**Teach how to write Stories:**
- How to write user stories?
- How to define acceptance criteria?
- How to estimate effort?

**Teach how to run planning meetings:**
- How to structure planning meetings?
- How to involve stakeholders?
- How to make decisions?

### Phase 3: Implement process (Month 3-4)

**Quarterly planning:**
- Define OKRs for the quarter
- Define Epics for each OKR
- Estimate effort and timeline
- Align stakeholders

**Sprint planning:**
- Break Epics into Stories
- Break Stories into Tasks
- Assign ownership
- Commit to sprint

**Daily standup:**
- What did you do yesterday?
- What will you do today?
- What blockers do you have?

**Retrospective:**
- What went well?
- What could be better?
- What will we do differently?

### Phase 4: Measure and improve (Ongoing)

**Track planning metrics:**
- Plan accuracy
- Scope clarity
- Estimation accuracy
- Dependency identification
- Stakeholder alignment
- Planning efficiency

**Gather feedback:**
- How is planning working?
- What's hard?
- What could be better?

**Iterate:**
- Adjust framework based on feedback
- Improve templates
- Improve process

## Common mistakes at professional level

| Mistake | Why it hurts | Fix |
|---|---|---|
| No consistent framework | Teams plan differently | Establish consistent framework |
| Vague templates | Plans are unclear | Create detailed templates |
| Not teaching planning skills | Teams don't know how to plan | Teach planning skills |
| Not measuring planning quality | You don't know if planning is working | Track planning metrics |
| Not gathering feedback | You don't know what's hard | Gather feedback from teams |
| Not iterating | Planning doesn't improve | Iterate based on feedback |
