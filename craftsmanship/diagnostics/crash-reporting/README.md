# Crash Reporting

Use this roadmap to build practical skill in crash reporting.

## What you will learn

- Capture unhandled failures with release context, grouping, and safe diagnostic detail.
- How the work changes from a guided change to an organization-wide standard.
- How to verify the result in a running system.

## Learning path

- [Junior](junior.md) — make a safe, guided change.
- [Middle](middle.md) — own local trade-offs.
- [Senior](senior.md) — design for production risk.
- [Professional](professional.md) — establish a measurable team standard.

## Practice

- [Tasks](tasks.md) — apply the topic to real work.

## How to use this guide

1. Start at the level that matches your current scope.
2. Complete one checklist item in a real service.
3. Answer the review questions before moving to the next level.
