## Levels

- **Junior:** make a clear, safe update in a known area.
- **Middle:** own a document or component and explain trade-offs.
- **Senior:** design a durable approach across a system boundary.
- **Professional:** establish shared standards, feedback loops, and measurable quality.

For every topic: start with the reader's task, keep a single source of truth, and update or remove information when reality changes.
