# Coupling and Cohesion

Use these lessons as short, practical guides for making design decisions.

## How to learn

- Start with the topic closest to your current problem.
- Read **Junior** for a guided local change.
- Use **Middle** to reason about a component.
- Use **Senior** for system boundaries and trade-offs.
- Use **Professional** to create repeatable team practice.

## Topics

Open a topic's `junior.md` first, then progress through the other levels as your scope grows.
