# Monitoring — Senior

Align monitoring with SLIs, capacity, dependency health, and business invariants. Detect silent correctness failures—not only crashes. Define alert ownership across shared dependencies and degraded modes.

Review alert precision, missed incidents, time to detection, and operator load. Test alerts during game days and ensure the monitoring path survives the failure it reports.

## Test yourself

1. Which metric detects wrong-but-successful responses?
2. Who owns a shared dependency alert?
3. Can monitoring survive regional failure?
4. Which missed incident requires a new signal?
