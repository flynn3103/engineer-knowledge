# SRE and Reliability — Middle

Use error-budget burn to decide release and reliability work. Design graceful degradation, load shedding, queue limits, retry budgets, and dependency timeouts before overload.

Reduce toil that is manual, repetitive, automatable, tactical, and unbounded. Automation must expose failure and ownership rather than bury it.

## Test yourself

1. Which request should be shed first?
2. How does a retry budget protect capacity?
3. What action follows fast budget burn?
4. Which toil is highest leverage?
