# SRE and Reliability — Senior

Own SLOs across dependencies, regional failures, recovery backlog, and organizational boundaries. Define incident roles, escalation, status communication, and postmortem actions.

Use postmortems to improve defenses, detection, response, and recovery—not assign blame. Track recurring failure, action completion, and risk accepted by product owners.

## Test yourself

1. How do shared dependencies affect SLO ownership?
2. Which degraded mode preserves the core journey?
3. What makes a postmortem action durable?
4. Who can accept reliability risk?
