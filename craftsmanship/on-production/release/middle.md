# Release — Middle

Automate builds, signing, registry publication, environment promotion, changelogs, and deployment evidence. Use semantic versioning for promised public compatibility, not internal ceremony.

Feature flags separate deployment from exposure but need owners, expiry, targeting tests, and removal. Release branches or trains help coordinated products but add merge and patch cost.

## Test yourself

1. Which step must be reproducible?
2. When is semantic versioning meaningful?
3. How does flag debt become production risk?
4. Which evidence should automation retain?
