# Pair and Mob Programming — Middle

## Goal

Choose collaborative programming deliberately and run sessions with useful flow.

## When to use it

- Spread knowledge through an unfamiliar area.
- Untangle a risky defect or production incident.
- Design a boundary that affects several people.
- Onboard a teammate through real work.

## Facilitation

- Set a concrete outcome and timebox.
- Rotate driver, navigator, and facilitator.
- Keep one problem on screen; park unrelated questions.
- Use short breaks and a written decision log.
