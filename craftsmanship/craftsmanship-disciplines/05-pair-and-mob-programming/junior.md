# Pair and Mob Programming — Junior

## Goal

Use shared work to learn faster and make decisions visible.

## Pairing roles

- Driver controls the keyboard and narrates small actions.
- Navigator watches the goal, asks questions, and spots risks.
- Switch roles often, usually every 10–20 minutes.

## Good session habits

- State the next small goal before typing.
- Keep tests and the diff visible.
- Pause when either person is confused.
- End by recording the decision and next step.

## Practice

Pair on a small bug. The navigator writes the failing-test idea; the driver implements it. Switch after green.
