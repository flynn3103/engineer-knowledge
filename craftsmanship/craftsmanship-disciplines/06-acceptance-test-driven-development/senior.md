# Acceptance Test-Driven Development — Senior

## Goal

Use acceptance examples to align product strategy, system boundaries, and delivery evidence.

## At scale

- Treat examples as contracts across services and teams.
- Define ownership for shared language and cross-team scenarios.
- Pair acceptance criteria with telemetry that confirms production outcomes.
- Use contract tests where one team depends on another team's behavior.

## Watch for

- Specifications written after implementation as paperwork.
- UI automation standing in for business understanding.
- A shared scenario suite with no owner or retirement policy.
