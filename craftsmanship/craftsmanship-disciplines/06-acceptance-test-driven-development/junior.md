# Acceptance Test-Driven Development — Junior

## Goal

Turn a user-facing rule into an example before writing the implementation.

## Start with an example

- Given a customer has an empty cart.
- When they add one item costing 10.
- Then the cart total is 10.

## Workflow

1. Discuss the example with product and engineering.
2. Write it in clear business language.
3. Automate only the examples worth keeping.
4. Implement until the example passes.

## Practice

For the next story, write one happy path and one important edge case before coding.
