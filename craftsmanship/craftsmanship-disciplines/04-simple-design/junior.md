# Simple Design — Junior

## Goal

Keep code correct, clear, and no more complex than today requires.

## Four rules, in order

1. Passes its tests.
2. Reveals intention.
3. Removes meaningful duplication.
4. Uses the fewest necessary elements.

## Apply them

- Make the behavior work first.
- Give values and functions honest names.
- Extract repeated knowledge, not merely similar-looking lines.
- Delete unused flags, wrappers, and branches.

## Practice

Take one small function and ask: can a new reader explain it, can one name improve it, and can anything be deleted without changing behavior?
