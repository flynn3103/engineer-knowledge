# Kata and Deliberate Practice — Junior

## Goal

Build skills through short, repeated exercises with immediate feedback.

## A practice loop

1. Choose one small kata.
2. Set a narrow focus, such as test names or tiny commits.
3. Solve it without looking up the answer.
4. Review what felt slow or unclear.
5. Repeat with one adjustment.

## Good kata topics

- FizzBuzz with TDD.
- Roman numerals.
- String calculator.
- Refactoring a small messy function.

Practice is not a production task. Optimize learning, not feature output.
